Community build · Know what you install

Transparent about trust.

The app and helper are ad-hoc signed; the PKG and DMG are unsigned and not Apple-notarized. On macOS 15 or later, first try to open the installer, then use System Settings → Privacy & Security → Open Anyway only if you trust this release. Review the source and compare the published SHA-256 checksum before installing.
