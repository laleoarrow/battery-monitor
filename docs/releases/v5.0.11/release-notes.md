# Wattson 5.0.11

**设置窗口回归 macOS 的键盘操作。** 用 `⌘W` 关闭、`⌘M` 最小化、`⌘H` 隐藏窗口，或按 `⌘,` 打开设置。进程白名单编辑框支持系统编辑菜单，透明度滑块可以用方向键调整。

从 5.0.3 升级还会获得新的 Energy Flow 布局与连续状态过渡。USB 设备接入时先显示连接提示，获得有效功率后再显示输出。进程列表按实际可见行数收缩，滚动条与圆角边缘保持间距。

[5.0.11 明暗设计图集](https://laleoarrow.github.io/battery-monitor/design/v5.0.11/) · [已发布的图标预览与 SVG 源文件](https://laleoarrow.github.io/battery-monitor/design/v5.0.3/)

安装 **PKG** 可获得完整应用与辅助程序，现有 PKG 或 Homebrew 用户也用此方式升级。**DMG** 只含应用，适合不安装辅助程序时使用。应用与辅助程序采用临时签名，PKG 和 DMG 未签名，也未经过 Apple 公证。
