# 极简电池功率桌面小组件设计

日期：2026-06-15

## 背景

当前 `电池功率` 是 Python/Tkinter 实现的 macOS 悬浮电池功率监视器。现有版本存在两个主要问题：

- 视觉上仍偏工具化，不够轻、不够优雅。
- 动画状态点、百分比、底部文字在小窗口内共享固定坐标，容易出现遮挡或拥挤。

这次设计目标是把现有 app 优化成更像桌面小组件的极简功率条，同时保留必要的功率拆解能力。

## 目标

1. 常驻窗口改成极简横条，优先显示总功率、电量百分比和状态点。
2. 总功率定义为：整机实际运行功率 + 电池充电功率。
3. 详情只在需要时出现：按住 `Cmd` 并悬停时展开，或通过右键菜单查看/配置。
4. 右键菜单提供桌面模式、置顶、高级分项、退出等设置。
5. 默认不要求管理员权限；高级分项功率作为可选估算功能。
6. 保持透明圆角干净，无黑边、黑角、文字遮挡。

## 非目标

- 这次不实现真正的 macOS WidgetKit 小组件。
- 这次不重写为 Swift 或 SwiftPM 项目。
- 这次不把 SSD 显示成瓦数，因为当前可用数据源没有可靠 SSD 功率字段。
- 这次不把 CPU/GPU/ANE 估算功率作为默认常驻信息。

## 常驻形态

常驻窗口采用更小的横向条形布局，信息只保留：

- 主数字：总功率，单位 W。
- 右侧：电量百分比。
- 小状态点：用颜色表达状态。

状态色：

- 充电：绿色。
- 外接电源且满电：蓝色。
- 放电：白色或中性色。
- 低电量放电：红色。

常驻形态不放 emoji，不把图标和文字混排，避免 Tkinter 在 macOS 上出现混合字体宽度计算问题。

## 总功率与详情功率

默认数据源继续使用 `ioreg -rd1 -c AppleSmartBattery`。

常驻总功率：

- 整机实际运行功率：优先使用 `PowerTelemetryData.SystemLoad`。
- 电池充电功率：优先使用 `ChargerData.ChargingVoltage` 和 `ChargerData.ChargingCurrent` 计算进入电池的功率；如果缺失，再按当前充电/放电状态规范化 `PowerTelemetryData.BatteryPower`。没有电池充电时按 0 处理。
- 总功率：整机实际运行功率 + 电池充电功率。

详情显示：

- 总功率。
- 整机实际运行功率。
- 电池充电功率或放电功率。
- 电量百分比。
- 当前状态说明，例如充电、外接电源、放电。

实现时需要保留安全回退：如果 telemetry 或 charger 字段缺失，使用电压和电流估算当前电池功率，但界面不要把估算值伪装成更精确的分项功率。

## 详情交互

详情展开方式：

- 按住 `Cmd` 并让鼠标进入小组件时，展开详情。
- 松开 `Cmd` 或鼠标离开后，恢复极简条。

右键菜单：

- 桌面模式：切换更像桌面小组件的行为。
- 置顶：切换 always-on-top。
- 高级分项：开启或关闭 CPU/GPU/ANE 估算采样。
- 退出。

常驻窗口不显示设置按钮，以保持极简和避免遮挡。

## 桌面模式

桌面模式用于模拟桌面小组件，而不进入 WidgetKit 工程。

行为：

- 窗口更小、更低存在感。
- 默认不置顶。
- 保持可拖动。
- 记住窗口位置。
- 可通过右键菜单恢复置顶或退出。

这只是当前 app 的桌面小组件模式，不会出现在系统 Widget Center。

## 高级分项

高级分项默认关闭。

开启后，app 才尝试使用 `powermetrics` 读取 CPU/GPU/ANE 估算功率：

- `powermetrics` 需要管理员权限。
- CPU/GPU/ANE 是估算值，应在界面标明“估算”。
- 如果权限不足或字段不可用，详情中显示高级分项未启用或不可用。
- 高级分项失败不影响常驻总功率、整机功率、电池功率。

SSD 不作为瓦数展示。后续如果需要，可单独设计磁盘活动或 IO 指标。

## 实现边界

保持现有 Python/Tkinter 单文件应用，但需要把以下逻辑整理成小函数：

- telemetry 解析与功率计算。
- 当前状态判定。
- 极简布局绘制。
- 详情布局绘制。
- 右键菜单和模式切换。
- 配置读取和保存。

Canvas 必须继续设置：

- `bd=0`
- `highlightthickness=0`

修改后必须把项目内 `battery_monitor.py` 同步到 `~/.battery_monitor.py`，并通过 `scripts/install.sh` 更新 `~/Applications/电池功率.app/`。

## 验证标准

实现完成后至少验证：

- 充电状态：总功率、电量、状态点、详情功率无遮挡。
- 外接电源且满电：显示不挤压，详情能表达电池充电为 0 或近似 0。
- 放电状态：总功率和状态点正确，详情显示放电功率。
- `Cmd` 悬停展开和恢复正常。
- 右键菜单能切换桌面模式、置顶、高级分项，并能退出。
- 窗口圆角透明，无黑边或黑角。
- 安装后的 app bundle 可以启动。

## 后续评估

真正的 macOS WidgetKit 小组件作为后续独立项目评估。它需要 Swift/WidgetKit 工程、数据共享机制和系统小组件生命周期设计，不纳入本次实现。
