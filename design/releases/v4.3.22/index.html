Process Activity · Light / Dark

Selected Safari shows the uniform 38 × 16-point action capsule. A charging fixture supplies the current App chart palette; the capsule tint uses the complete bar’s deepest endpoint independently of the score. The renderer checks both dimensions and endpoint color.

Scores 84, 46 and 8.1 are illustrative Activity Scores derived from CPU and idle wakeups, not watts or percentages of battery use. These view-owned bitmap renders create no app/window or helper request and do not demonstrate composited native glass or pointer glow motion.

Power artwork · full state matrix

The production Flow and Lane drawing paths use fixed supply-state fixtures. Charging uses green, plugged-in states use blue, mixed supply uses amber for battery assistance, and on-battery adapter artwork is neutral and dimmed.
