currently installed Wattson. No earlier proposed runtime designs were supplied.

`.build/pro-design-review.noindex/` directory.

These are unapproved visual concepts, not production renders or implemented UI.

4h 25m runtime; that value is illustrative and must not describe actual installed
readings. Circular/progress decorations and information/disclosure controls do
not establish new data or implemented behavior. The product still uses macOS's
internal-battery time-to-empty estimate, and suppresses numbers on external power.

No application code, preferences, installed bundle, helper, or installer was
changed during this design consultation.
