# Settings baseline

Six Classic layout images show the production Settings controller before the native hierarchy redesign, in Light and Dark. Captured from hidden AppKit windows in the disposable ARM macOS 26.6.1 GUI VM; preferences are in memory and system/update operations are mocked.

These are view-cache layout renders, not WindowServer screenshots or Liquid Glass evidence. Native Glass cache images were rejected because native material surfaces obscured the controls. No installed app, helper, production preference, host desktop or privacy setting was changed.

See `capture-manifest.json` for frozen source hashes and image checksums.
